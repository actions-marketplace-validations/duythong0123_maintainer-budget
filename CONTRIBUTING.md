# Contributing

The project is early and precision matters more than feature count.

Useful contributions include:

- false-positive candidate clusters,
- repeated feedback that the baseline failed to group,
- bot/automation comments that escaped filtering,
- stale conventions that should not become rules,
- repository-specific conventions with clear review evidence.

Please include source PR/comment links when possible. Do not submit private repository review data unless you have permission to share it.

Run tests with:

```bash
python -m unittest discover -s tests -v
```
